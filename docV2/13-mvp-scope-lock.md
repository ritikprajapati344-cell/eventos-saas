EventOS AI V2 – MVP Scope Lock Document (MSLD) v1.0
===================================================

1\. Purpose
-----------

This document defines:

*   What will be built in V2 MVP

*   What will NOT be built in V2 MVP

*   Success criteria

*   MVP boundaries

Goal:

Launch the smallest version that proves the vision.

2\. MVP North Star
==================

User should be able to type:

`   Create a Sunil Grover show in Ahmedabad.  1500 seats.  ₹50L target revenue.   `

And EventOS AI should generate:

`   Event Blueprint  Sponsor Strategy  Ticket Plan  Timeline  Tasks  Finance Forecast  Marketing Plan  Risk Report   `

Then:

`   Approve  ↓  Execute   `

This is MVP success.

3\. What MVP MUST Do
====================

AI Command Center
-----------------

Homepage becomes:

`   EventOS AI  What would you like to do today?  [ Command Box ]   `

Features:

*   Text command

*   Suggested prompts

*   Command history

Required.

Clarification Engine
--------------------

If information is missing:

AI asks questions.

Example:

`   Budget?  Venue?  Date?  Target Audience?   `

Required.

Blueprint Generator
-------------------

Generates:

### Event Plan

### Ticket Plan

### Sponsor Plan

### Timeline

### Tasks

### Finance Forecast

### Marketing Plan

### Risk Report

Required.

Approval Engine
---------------

Supports:

`   Approve Blueprint  Approve Tasks  Approve Timeline  Approve Tickets   `

Required.

Execution Engine
----------------

Creates:

`   Event  Tasks  Timeline  Ticket Categories   `

using existing V1 infrastructure.

Required.

Memory Engine
-------------

Stores:

`   Blueprints  Past Events  Past Sponsors  Past Vendors  Lessons Learned   `

Required.

History
-------

Stores:

`   Past Commands  Past Blueprints  Past Executions  Past Approvals   `

Required.

4\. What MVP Will NOT Do
========================

No WhatsApp Sending
-------------------

AI may create drafts.

AI may not send.

No Email Sending
----------------

AI may prepare emails.

AI may not send.

No Mobile App
-------------

Web only.

No Multi-Agent UI
-----------------

Agents exist internally.

User never sees them.

No Advanced Enterprise Roles
----------------------------

Owner role only.

No CRM Integrations
-------------------

Future phase.

No Calendar Integration
-----------------------

Future phase.

No Payment Execution
--------------------

Never in MVP.

No Automatic Research Crawling
------------------------------

Research only when user requests.

5\. MVP User Flow
=================

Step 1

User signs in.

Step 2

AI asks onboarding questions.

Example:

`   What type of events do you organize?  Comedy?  Corporate?  Concerts?  Weddings?   `

Step 3

User enters command.

Step 4

AI asks clarifications.

Step 5

AI generates blueprint.

Step 6

User reviews.

Step 7

User approves.

Step 8

AI executes approved items.

Step 9

AI tracks event progress.

6\. First Demo Scope
====================

Locked demo:

`   Create a 1500-seat Sunil Grover comedy show in Ahmedabad with ₹50L revenue target.   `

AI must generate:

✅ Event Plan

✅ Ticket Categories

✅ Sponsor Strategy

✅ Finance Forecast

✅ Marketing Plan

✅ Timeline

✅ Tasks

✅ Risks

Then:

`   Approve  ↓  Create Records   `

7\. Success Metrics
===================

User creates first event:

Less than 5 minutes.

Blueprint quality:

Professional event company level.

Approval flow:

Understandable without training.

Execution:

Creates correct records.

Memory:

Future events improve from past events.

8\. MVP Screens
===============

Only these:

`   EventOS AI  My Events  Approvals  History  Reports  Settings   `

Everything else becomes:

`   Advanced Data   `

and is hidden from normal users.

9\. Existing V1 Modules
=======================

Keep:

`   Events  Tasks  Timeline  Sponsors  Artists  Vendors  Ticketing  Finance  Expenses   `

But:

They become engines.

Not primary UI.

10\. Biggest Rule
=================

MVP is NOT:

`   Event Management Software   `

MVP IS:

`   AI Event Operator   `

User talks.

AI plans.

User approves.

AI executes.

11\. Scope Lock
===============

Anything outside this document:

`   NOT MVP   `

No matter how exciting.

No matter how useful.

No matter how cool.

12\. Final Definition
=====================

EventOS AI V2 MVP:

`   ChatGPT for Event Operations  with  Blueprints  +  Approvals  +  Execution  +  Memory   `

Nothing more.

Nothing less.
